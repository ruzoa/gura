# 다빈치코드 (`games/davinci.js`)

2~4명 추리 타일 게임입니다. 화면 이름 '다빈치코드', 디스플레이 '다빈치'. 공개 전에 이름을 확인해야 합니다(상품명, 원작 Coda). 타일 그림은 새로 그렸습니다.

## 규칙
- 흑·백 0~11 24개 + 조커 2개(설정 `joker`, 기본 켬). 2~3명 4개, 4명 3개로 시작. **시작 타일에는 조커가 없음**(모두가 자리를 고르는 단계를 없앰). 나머지는 탁자 가운데에 흩어 둠.
- 첫 차례는 공통 주사위 또는 선 플레이어 설정.
- 차례: `draw` 흩어진 패에서 하나를 집음(남은 패가 없으면 건너뜀) → `guess` 추리 → 맞히면 `cont` 계속/멈춤(멈추면 숨겨서 놓음) → 틀리면 집은 타일을 공개해서 놓음. 남은 패가 없을 때 틀리면 `reveal` 내 타일 하나 공개(하나뿐이면 저절로).
- 정렬: 숫자 오름차순, 같은 숫자는 흑이 왼쪽. 조커는 어디든. 조커 때문에 놓을 자리가 여럿이면(`legalSlots`) `place`에서 고름. 틀린 뒤 놓을 때도 같음.
- 타일이 모두 공개되면 탈락, 마지막 한 사람이 승리. 탈락 순서대로 뒤 순위.
- 제한 시간 기본 30초(10~120), 단계마다 새로 시작. 넘기면 뽑기·추리·놓기·공개는 무작위, 계속 고르기는 멈춤.
- 항복: 타일을 모두 공개. 내 차례였으면 집은 타일은 패로 돌아감.

## 엔진 (`H.dv`)
- `ph`: draw → guess → show(`SHOW_MS` 판정 전) → res(`RES_MS` 결과) → cont / place / reveal → 다음 차례. `done`은 끝.
- 판정은 show가 끝날 때(`judge`) 하므로 화면이 결과를 앞지르지 않음. 탈락·승리 처리는 res가 끝날 때.
- `rk[자리]`: `{u,id,o,w}`. `u`는 값과 상관없는 무작위 번호(화면이 타일을 가리킴), `id`는 색×13+숫자, `o` 공개, `w` 틀린 숫자. `pool`은 `{u,id,x,z,r}`(흩어진 자리를 방장이 정해 모두 같게 봄). `held`는 집은 타일.
- `snap`: 값은 공개된 타일·자기 타일·끝난 뒤만. `id`는 보내지 않음. 놓을 자리 `at`은 차례인 사람에게만.
- 봇(쉬움, `oneBotLv`): 무작위로 집고, 이미 공개된 숫자와 그 타일에서 틀린 숫자만 피해 추리(앞뒤 타일로 좁히지 않음, 조커는 안 부름). 맞히면 30%만 계속. 시간 초과 추리도 같은 함수.

## 화면
- 공통 앉은 카메라(`noView`로 고개 돌리기 끔). 남은 패는 게임 내내 눕혀 흩어 둠. 줄은 자리마다 호를 따라 세우고(`rackPose`) 앞면은 주인 쪽, 공개하면 가운데 쪽으로 쓰러져 앞면이 위로. 줄이 길면 타일을 줄임(`rackK`, 내 줄은 화면 폭 기준). 집은 타일은 줄 끝에.
- **앉은 카메라 예외(사용자가 정함):** 내 추리 단계에서 상대 패나 이름표를 누르면 그 줄로 이동·줌(`camNow`, 0.36초). 옆자리는 줄이 보이도록 고개를 72%만 돌림. 빈 곳·Esc는 복귀, 결과가 끝나면 복귀, 계속해도 복귀. 다른 사람 차례에는 카메라가 움직이지 않고 지목된 타일에 금색 테두리·공중 숫자, 이름표 아래 `7?`.
- 다가가면 이름표·버튼을 숨기고 아래에 내 줄 띠, 타일을 고르면 그 색의 나무 자판(0~11·조커·추리). 숫자를 고른 뒤 [추리](두 번 눌러 놓기 설정이면 다시 누름). 설정 `help`면 내 타일·공개된 타일·틀린 숫자를 흐리게.
- 틀린 숫자는 타일 앞 펠트의 작은 글자.
- 계속/멈춤은 공통 `#btnPlay`·`#btnPass`. `place`·`reveal`은 아래 내 줄 띠에서 고름(WebGL 없는 화면과 같은 길).
- 공통 스포트라이트(`#dim`)는 쓰지 않음. 클래스 이름 `.dim`은 공통 CSS라서 쓰면 안 됨(`.dm`).
- 결과 창은 `overDelay` 1.8초 뒤. 끝나면 남은 타일이 모두 쓰러짐.
- WebGL이 없으면 남은 패는 흑·백 버튼 둘(그 색 무작위), 상대 줄은 버튼.
