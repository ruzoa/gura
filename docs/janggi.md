# 장기 (`games/janggi.js`)

화면 틀(이름 칸·시계·3D 카메라·시작 연출·미리 고르기)은 체스(`docs/chess.md`)를 따릅니다. 이 기능을 바꾸면 이 문서를 고칩니다.

## 규칙 (사용자와 정한 것, 2026-10-30)

- **상차림:** 초가 먼저 고르고(`ph:'set'`), 한은 초의 상차림을 보고 고름. 네 가지 `SETUPS`(자기 쪽 왼쪽부터 마상마상·마상상마·상마마상·상마상마). 고를 시간 20초(`SET_MS`, 시계와 따로), 넘으면 마상마상. 그 뒤 초가 첫 수.
- **빅장:** 금지 아님. 두 장이 마주 본 뒤(`facing`) 받은 쪽이 응수했는데도 마주 보면 그 자리에서 무승부(`bik`). 불이익 없음.
- **반복(`rep`):** 클립보드 플립 칸 `3회까지`(기본) / `무제한`. 3회까지면 같은 국면(같은 쪽 차례, `repKey`)이 네 번째로 나오는 수는 금수(빨간 ✕ + 금지 소리). 단 양쪽 모두 덤을 뺀 점수가 30점(`LOW`) 미만이면 둘 수 있고, 두면 점수 판정(`rep`). 둘 수 있는 수가 모두 반복 금수면 점수 판정(`stuck`).
- **점수:** 차 13, 포 7, 마 5, 상·사 3, 졸·병 2(한쪽 72). 30점 기준에는 덤을 넣지 않고, 승패를 가릴 때만 한에 1.5(`DUM`)를 더함 → 비기지 않음.
- **한 수 쉬기:** 장군이 아니면 언제나(내 이름 칸 → '한 수 쉬기'). 쉬기도 반복 국면에 셈. 그래서 스테일메이트가 없음.
- **끝:** 외통(`mate`), 빅장(`bik`), 시간 초과 패배, 항복·탈주, 점수 계산 합의(`agree`, 내 이름 칸 → '점수 계산 제안', 한 판에 세 번, 상대가 그냥 두면 없던 일), 반복 점수 판정. 봇끼리만 앉은 판은 600수(반 수)에서 점수 판정(`long`, 테스트·빈 방 안전장치).
- **시계:** 체스와 같은 총 시간 + 추가 시간. 기본 10분 + 10초(공식 값이 아니라 정한 값). 봇 자리는 시계가 안 감.
- **선 플레이어:** `pickfirst`(선택이면 방장이 대기실 [선]으로 초를 고름), 바로 시작하면 초·한을 바꿈(`H.jLast`).

## 엔진

- 판 `Int8Array(90)`, 칸 번호 `y*9+x`(y 0 = 초 끝 줄). 기물 1 졸 2 사 3 상 4 마 5 포 6 차 7 장, 한은 +8.
- 궁성 대각선 `PD`(그어진 선 위로만: 가운데는 네 방향, 모서리는 가운데 쪽 하나). 차·포·장·사·졸(앞쪽 대각선만) 모두 이 표를 씀.
- 포: 포가 아닌 기물 하나를 넘어야만 움직임, 포는 잡지 못함(궁성 대각선 넘기 포함). 마·상: 멱(`HP`).
- `gen`(유사 합법) → `legal`(장이 공격받지 않는 수 + 장군이 아니면 `PASS`), `attacked`(거꾸로 찾는 공격 판정), `make`/`unmake`(해시 두 줄 `Z1`·`Z2`), `replay(su, mv)`로 지금 국면·반복 횟수.
- 수 글자: `ffTT`(칸 번호 두 자리씩), 쉬기 `pp`. 진행 기록은 `moveName`(자기 쪽에서 센 줄·세로줄 + 기물 이름).
- 방장 상태 `H.c`: `ph`(set/play), `su`(색별 상차림, -1 아직), `sdl`(상차림 마감), `mv`, `cp`(자리별 잡은 기물), `lm`, `chk`, `bik`, `rem`, `since`, `dr`·`drN`(점수 계산 제안), `res`(`w`, `why`, `sc`=[초 점수, 한 점수+덤]).

## 봇

- 쉬움 하나(`oneBotLv`). 두 수 + 잡는 수 정리 탐색(`search`·`qs`, 노드 상한), 평가는 기물 점수 + 졸 전진 + 사가 장 곁 + 마·상 나옴. 흔들림 ±1.2점, 12%는 크게 잃지 않는 수 중 아무거나.
- 빅장: 마주 본 국면에서 응수가 계속 마주 보면 0(비김)으로 봄. 반복: 금수는 빼고, 왔던 국면은 횟수만큼 감점(무제한에서도 되풀이하지 않게). 쉬기는 조금 감점.
- 상차림은 무작위. 점수 계산 제안은 점수로 이기면 받음.
- 방장 화면에서 바로 계산(일꾼 없음, 탐색이 짧음).

## 화면

- 3D: 공통 테이블 가운데 원목 판(`drawBoardTex`: 9×10 먹선, 궁성 대각선, 졸·포 자리 표시, 앞뒤가 같아 돌려도 다시 그리지 않음) + 팔각 알(`CylinderGeometry` 8각, 위가 조금 좁음, 먹선 껍질). 크기 세 단계 `PR`: 장 > 차·포·마·상 > 사·졸. 윗면은 캔버스 글자(`faceTex`): 초 청록 楚車包馬象士卒(살짝 기울여 흘림 기운), 한 붉은 漢車包馬象士兵. 실제 판처럼 각자 자기 쪽에서 바로 읽힘: 내 알은 바로, 상대 알은 거꾸로, 잡은 알은 잡은 사람 쪽으로(`orient`, 관전자는 초 쪽. 윗면 무늬의 로컬 +x가 글자 위쪽이라 y축 +90°면 화면 위). 카메라는 돌지 않고 판을 뒤집을 때 알 자리만 바꾸므로(`pW`) 방향은 '판이 뒤집혔나'가 아니라 '누구 알인가'로만 정함(예전에는 한 쪽에서 글자가 거꾸로 보이는 버그). 알 바닥은 판 무늬·표시 원보다 위(`PY`), 잡은 알은 천 윗면 위(`GY`). 2D 판도 상대 글자를 180° 돌림.
- 카메라: 바로 위에서(탑뷰, 오목·쿼리도와 같은 `tvBox`). 판 가운데 = 화면 가운데, 위아래는 이름 칸 자리. 잡은 알은 판 옆(`'h'`) 또는 앞뒤(`'v'`) 중 판이 더 크게 보이는 쪽(`j3Layout`). 판은 앞뒤 여백이 넓음(`BZ=HZ+.62`). 한을 잡으면 알 자리를 뒤집음(`flipped`).
- 표시: 마지막 수 노란 원, 고른 알 초록(살짝 들림), 갈 점 점·잡을 점 고리, 반복 금수 빨간 ✕, 못 움직이는 알을 누르면 금지 소리 + 멱·장군·묶은 상대 기물이 잠깐 빨강(`blockers`), 장군은 장 밑 붉은 빛 + 두 음, 빅장은 두 장 사이 붉은 띠 + 낮은 두 음.
- 이름 칸: 초·한 점, 이름, 시간(상차림 중이면 고를 시간, 5초 아래 깜빡), 점수(덤 포함)로 앞서면 `+차이`. 내 칸을 누르면 '한 수 쉬기'(못 쉬면 흐림 + 금지 소리) · '점수 계산 제안'.
- 상차림: 안내 줄 '상차림' + 한글 단추 넷(마상마상·마상상마·상마마상·상마상마, 자기 쪽 왼쪽부터). 3D는 내 쪽 끝 줄 아래 판 나무 띠 가운데(`.jg-su`, 자리는 카메라를 정할 때 `--sux`·`--suy`·`--suw`·`--suh`), 2D는 안내 줄 옆. 누르면 내 끝 줄에 반투명 미리 보기, 다시 누르면 되돌림, [정하기](또는 두 번 눌러 놓기). 정해진 마·상은 위에서 차례로 내려앉음.
- 시작 연출 3.3초: 판 내려앉기 → 졸·병 물결(내 왼쪽부터) → 사 → 포 → 차 → 장(마지막, 쿵) → '○○님이 초로 먼저 시작합니다' → 상차림. 바로 시작 1.7초: 판 그대로, 알이 같은 순서로 처음 자리로 미끄러지고 마·상은 들어 올려 치움(`regather`).
- WebGL이 없으면 2D 판(SVG, `pieceSvg` 팔각 알).
- 대기실 홀로그램 말: 楚 장 알과 漢 차 알(`G.holoPiece(재질 함수)`, 공통 `frontHoloPiece`가 부름).
