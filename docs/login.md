# 로그인·도토리 (`core/auth.js`, `core/pouch.js`)

게스트로 그대로 놀 수 있고, 구글로 로그인하면 도토리를 모으고 아바타를 꾸밀 수 있습니다.
**`core/auth.js`의 `FB_CONF`가 비어 있으면 모두 꺼져서 예전과 똑같습니다**(g. 표시·복주머니·잠금 없음).

## 화면

- **게스트 표시:** 로그인하지 않은 사람 닉네임 앞에 작고 흐린 `g.`(`.gtag`). 방장이 붙이므로 참가자가 뗄 수 없습니다. `g.`로 시작하는 닉네임은 쓸 수 없습니다(`cleanNick`·`myNick`이 뗌).
- **복주머니:** 대기실에서 내 자리에 앉아 있으면 디스플레이 오른쪽 나무 띠(시작 버튼과 맞은 자리, `PO_X` 1.3)에서 구멍이 열리고 올라온 뒤 구멍이 닫힙니다. 내 화면에만 있습니다. 게임이 시작되거나 홀로그램·설정 판자·참여하기·아바타 변경 중에는 들어갑니다.
  - 게스트: 납작한 빈 주머니. 누르면 나무 꼬리표에 로그인 버튼.
  - 로그인: 도토리가 많을수록 통통해짐(100개쯤 가득). 누르면 입구가 벌어지며 도토리가 보이고, 꼬리표에 개수·오늘 받은 수·로그아웃.
  - 판이 끝나고 받은 도토리는 대기실로 돌아와 주머니가 올라오면 위에서 하나씩 떨어져 들어가고 `+N`이 잠깐 뜹니다.
- **처음 로그인:** 꼬리표가 '탁자에서 쓸 이름'을 묻습니다(구글 이름은 쓰지 않음). 정할 때까지 꼬리표가 닫히지 않습니다.
- **아바타 잠금:** 게스트는 모양(종류·동물)만 바꿀 수 있고 장식·색칠은 자물쇠. 누르면 로그인 꼬리표. 게스트일 때는 전에 칠한 그림·장식도 남에게 보내지 않고(`myAvStr`) 내 화면에도 그리지 않습니다. 로그인하면 다시 보입니다.
- **앱 안 브라우저(카카오톡·인스타그램 등):** 구글이 로그인을 막으므로 꼬리표가 바깥 브라우저로 열기(카카오톡 `kakaotalk://web/openExternal`, 안드로이드 크롬 intent, 그 밖에는 주소 복사)를 띄웁니다.

## 저장 (Firestore)

| 위치 | 값 | 누가 |
| --- | --- | --- |
| `users/{uid}` | `nick`, `av`(모양 글자), `paint`(칠한 그림 PNG, 6만 자까지), `acorn`, `dayN`(오늘 받은 수), `at`(마지막으로 받은 시각) | 본인만 읽고 씀 |
| `peers/{uid}` | `peer`(지금 PeerJS 번호), `at` | 본인만 씀, 누구나 읽음 |

- 로그인하면 계정의 닉네임·아바타·그림을 이 기기에 덮어씁니다(계정이 처음이면 이 기기 것을 계정에 올림). 바꾸면 1.5초 모아서 계정에 저장(`auProfSave`).
- localStorage `gura-login`: 로그인한 적이 있으면 1(다음 접속 때 Firebase를 바로 받아 로그인 상태를 되살림). 게스트는 Firebase 파일을 받지 않습니다.

## 방장이 로그인을 확인하는 방법

로그인한 사람은 자기 PeerJS 번호를 `peers/{uid}`에 적고(`auPeer`, `guestHello` 때) hello에 `uid`를 싣습니다. 방장은 `peers/{uid}`를 읽어 그 연결의 번호(`conn.peer`)와 같을 때만 `g.`를 뗍니다(`auHostVerify`, 적는 중일 수 있어 3번까지 다시 읽음). 남의 uid를 대도 번호가 달라서 통과하지 못합니다. 게임 중에 확인되면 이름은 다음 대기실부터 바뀝니다.

## 도토리

- 결과 화면이 되는 순간(`applyView` → `auGameEnd`): 끝까지 한 사람 1개, 왕관(1등, `cr`)이면 1개 더. 항복·시간 초과·탈주·관전은 없음.
- 하루(한국 시각 자정 기준) 30개(`ACORN_DAY`), 받은 뒤 1분(`ACORN_GAP`) 안에는 못 받음.
- 같은 제한을 보안 규칙(`firebase/firestore.rules`)이 지킵니다. 서버가 없어서 게임 결과 자체는 확인하지 못합니다(조작하면 하루 30개까지는 가능). 돈이 오가게 되면 서버 확인이 필요합니다.
- 아직 쓰는 곳(꾸미기 상점)은 없습니다. 쓰게 되면 규칙에 '줄이기' 조건을 더해야 합니다.

## 켜는 방법 (한 번만)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만듭니다(애널리틱스는 꺼도 됨). 무료(Spark) 요금제로 충분합니다.
2. **Authentication → 시작하기 → 로그인 방법 → Google** 사용 설정. 프로젝트 공개용 이름은 `탁자하나`로(구글 로그인 창에 보이는 이름).
3. **Authentication → 설정 → 승인된 도메인**에 `ruzoa.github.io` 추가.
4. **Firestore Database → 데이터베이스 만들기**(위치 `asia-northeast3` 서울, 프로덕션 모드) → **규칙** 탭에 `firebase/firestore.rules` 내용을 붙여 넣고 게시.
5. **프로젝트 설정(톱니) → 내 앱 → 웹 앱 추가(`</>`)** 후 나오는 `firebaseConfig`의 `apiKey`·`authDomain`·`projectId`·`appId`를 `core/auth.js`의 `FB_CONF`에 넣고 올립니다. (`apiKey`는 공개돼도 되는 값이고, 막는 것은 보안 규칙입니다.)

## 테스트

`window.AUTH_MOCK`(로그인·Firestore 흉내: `onUser`·`login`·`logout`·`get`·`put`·`award`)을 페이지보다 먼저 넣으면 Firebase 없이 켜집니다. 엔진 테스트는 로그인이 꺼진 상태(`myTagNick` = 닉네임)로 돕니다.
