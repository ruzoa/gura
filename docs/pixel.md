# 픽셀 (`games/pixel.js`)

2~4명이 슬라이더 둘로 말을 놓아 줄을 잇는 추상전략 게임입니다(에리얼 레이든, 2007, 2008 멘사 셀렉트). 화면 틀은 쿼리도·동물장기를 따릅니다. 이 기능을 바꾸면 이 문서를 고칩니다.

## 규칙 (원작 룰북, 2026-11-04 사용자와 확정)

- 판: 8×8에서 네 귀퉁이를 뺀 60칸. 각자 가운데 네 칸에 말 하나(2명은 대각선), 두 슬라이더는 첫 플레이어 말에서 만남. 시작 자리는 방장이 무작위로 돌려 시계 방향으로 배정(3명은 한 칸 빔).
- 차례: 슬라이더 하나를 움직여 교차점의 빈 칸에 말을 놓음. 말은 건너뛰되 멈추지 못함.
- 승리: 2~3명 4목, 4명 3목(가로·세로·대각선, 더 길어도 승리). 목표는 시작 인원으로 정하고 항복해도 그대로.
- 판이 다 차거나 둘 칸이 없으면(사용자 결정) 끝. 2~3명은 3줄, 4명은 2줄이 가장 많은 사람 승리, 같으면 무승부(일부만 같으면 공동 순위). 빈칸 없이 이어진 묶음 하나가 한 줄(`linesOf`).
- 제한 시간(기본 30초): 지나면 둘 수 있는 칸에 무작위. 패배 아님. 항복·탈주한 사람의 말은 판에 남고 차례를 건너뜀.
- 선: 첫 판은 공통 첫 차례 주사위(`pickfirst` 선택이면 방장이 고름), 바로 시작은 지난 판 선의 다음 사람(`H.pxlLast`).
- 말 수(파랑·주황 30, 노랑 20, 분홍 15)는 앱에서 세지 않음: 60칸을 나눈 만큼은 모두 가짐.

## 엔진

- 칸 = `y*8+x`(y 0 = 화면 위). `b[칸]` 0 빈 칸, 자리 + 1. 방장 상태 `H.pxl`: `cnt`, `need`, `A`(선), `b`, `st`(처음 칸, 선부터 차례대로), `sq`(교차점), `lm`, `mv`, `win`(빛낼 칸), `ln`(줄 판정 때 자리별 줄 수), `res`(`why` line/count/last, `w`, `stuck`).
- 봇 4단계(`G.botLvs`: 쉬움·중간·어려움·극악, lv 0~3, 공통 `botLvNames`).
  - 쉬움: 탐색 없음. 이기는 칸은 두고, 다음 사람 승리 칸 막기·내 줄 잇기를 좋아함. 다음 사람에게 승리를 여는 수는 차례의 70%에서만 피함.
  - 중간·어려움·극악(`think`): 2명은 알파-베타 + 국면 기억, 3~4명은 자리마다 값을 따로 들고 각자 자기에게 좋은 수를 둔다고 보고 읽음(좋은 수 7개만). 다음 사람이 바로 이기는 수는 더 읽지 않고 잘라 냄.
  - 중간 2수·흔들림 30, 어려움 7수(3~4명 4수)·흔들림 2·0.25초, 극악 흔들림 없음·1.2초(2명은 처음 국면에서 약 9수, 3명 7수·4명 6수까지).
  - 어려움·극악은 Web Worker(같은 파일)에서 계산. 답이 오기 전에 판이 바뀌면 버리고, 일꾼이 없으면 바로 계산.

## 화면

- 3D: 공통 테이블 가운데 원목 틀 + 60칸 판(귀퉁이는 나무 덩어리), 틀에 홈·좌표(A~H, 1~8). 말은 자리 색 네모 타일(도트 그림 윗면). 슬라이더는 유리 띠 둘 + 놋쇠 받침, 교차점 고리는 지금 차례 사람 색.
- 카메라: 바로 위, 판 가운데 = 화면 가운데(`tvBox`). 모두 같은 방향에서 봄.
- 조작: 점이 찍힌 칸을 누르거나 슬라이더를 끌면 미리 보기 → [놓기](두 번 눌러 놓기면 같은 칸 다시). 끄는 슬라이더만 움직이고 다른 쪽은 교차점 자리로. 교차점을 잡으면 끄는 방향으로 슬라이더가 정해짐. 둘 수 없는 칸에 끌면 빨강, 놓으면 금지 소리. 상대 차례에 미리 고르기는 없음(교차점이 바뀌므로). Esc는 미리 보기 취소.
- 수가 오면 슬라이더 0.24초 → 말이 내려앉음. 끝나면 줄을 금빛으로 비추고 결과 창은 1.9초 뒤(`G.overDelay`). 줄 판정이면 이름 칸·결과 창에 줄 수.
- 시작 연출: 로비 카메라 → 위, 판, 말 차례로, 슬라이더는 홈 끝에서 기다림, 주사위가 멈추면 첫 말로 모임. 바로 시작은 말이 떠올라 사라지고 처음 말이 떨어진 뒤 알림.
- WebGL이 없으면 2D 판(SVG), 끌기 없이 칸 누르기.
- 홀로그램 말: 도트 여섯 + 슬라이더 둘(`G.holoPiece`).
