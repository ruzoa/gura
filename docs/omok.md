# 오목 (`games/omok.js`)

> 원래 `CLAUDE.md` 파일 구조 표에 있던 자세한 설명입니다. 이 기능을 바꾸면 이 문서를 고칩니다.

오목 규칙 엔진(순수 함수 `judge`·`scanFours` 등: 장목 3종, 3-3·4-4 3종, 5목 우선, 거짓 3), 오프닝(없음·Swap·Swap2), 체스 시계 규칙(총 시간+추가 시간, 시간 초과 패배. 시간은 이름 칸(상대는 판 위쪽, 나는 판 아래쪽에 `CHIP_GAP` 띄움(`chipsAt`))에만 보이고 3D 시계 물건은 없음), 봇, 방 설정 레버(자유·커스텀·렌주, 세부 설정 접기), 선 플레이어는 쿼리도와 같은 '선 플레이어' 선택·무작위 버튼(`pickfirst`, 선택이면 이름표 메뉴 [선], 무작위면 랜덤, 주사위 연출은 아직 없음. 결과 화면에서 바로 시작하면 이긴 사람이 선), 공통 테이블 한가운데 3D 오목판(무늬는 나무판과 한 몸)과 바둑통 둘(내 통 오른쪽 아래·상대 통 왼쪽 위, 넓은 화면은 판 옆·좁은 화면은 판 위아래 모서리, 차례인 사람 통 둘레에 노란 고리(누구 차례인지, 시간은 아님), 놓은 돌 수만큼 통이 빔), 바로 위 자기 카메라, 누르면 반투명 미리 보기 → [놓기](상대 차례에도 미리 골라 둘 수 있고, 상대가 그 자리에 두거나 금수가 되면 지워짐), 처음 고를 때 통에서 돌 하나를 집어 듦(돌이 통 위로 떠오르고 '자르륵' 소리. 같은 칸을 다시 누르거나 Esc·내 통 누르기로 취소하면 통으로 내려앉음. 상대에게도 방장을 거쳐 `hold`로 알려 상대 통 위에도 돌이 떠 보임, 봇은 차례가 오면 집어 듦), 돌은 바로 위에서 툭 놓이고 통에서 날아오지 않음(놓으면 딱 소리, 차례 시작 소리는 없음), 내 통을 누르면 집는 소리(나만 들림, 횟수 제한 없음), 안 되는 곳을 누르면 글 대신 금지 소리, 안내 줄은 오프닝 단계(오프닝 2/3)·흑백 고르기·결과만, 10초 남으면 이름 칸 시간이 빨갛게 깜빡임, 금수는 빨간 ✕, 이긴 줄 표시, 시작 연출 2.4초: 판·통 내려앉기 → 통에 돌 쏟아지기, 바로 시작은 통만 다시 채움, 2D 판(SVG), 기보 복사 (최대 2명, 빠른 모드 없음, `tests/omok.cases.js`)
