# 쿼리도 (`games/quoridor.js`)

> 원래 `CLAUDE.md` 파일 구조 표에 있던 자세한 설명입니다. 이 기능을 바꾸면 이 문서를 고칩니다.

쿼리도 규칙 엔진, 봇, 공통 테이블 위 3D 보드(바로 위 90도 자기 카메라, 참가한 사람 앞에 보드와 떨어진 진갈색 보관함(홈 10개)에 벽을 세워 둠, 말 점프·벽 날아가기, 누르면 반투명 미리 보기 → [놓기]로 확정, 내 보관함의 벽을 눌러 고르면 살짝 올라오고 벽 모드, 개인 설정 '두 번 눌러 놓기'(`gura-dbltap`), 시작 연출: 로비 카메라→바로 위 카메라·보드 내려앉기와 칸 솟기·보관함과 벽 꽂기·말 떨어지며 목표 줄 긋기·첫 차례 룰렛(공통 `firstPick` + `roulette.js`: 마지막 말의 목표 줄이 끝난 뒤 0.5초 쉬고 → 모든 말에 후보 고리가 0.4초 켜지며 신호음 → 돌면서 느려져 멈춤. 빠른 칸 수가 판마다 달라 연출은 약 9~11초. 방 설정 '선 플레이어'를 선택으로 하면 방장이 대기실에서 선을 고르고 룰렛 없이 약 4초), 대기실은 공통 테이블). 벽 수는 공식 규칙(2명 10개, 4명 5개). WebGL이 없으면 2D 보드(SVG) (카드 없음, 최대 4명, 빠른 모드 없음)
