# 쿼리도 (`games/quoridor.js`)

> 원래 `CLAUDE.md` 파일 구조 표에 있던 자세한 설명입니다. 이 기능을 바꾸면 이 문서를 고칩니다.

쿼리도 규칙 엔진, 봇, 공통 테이블 위 3D 보드(바로 위 90도 자기 카메라(판 가운데 = 화면 가운데, 양옆 8/16px만 남기고 폭 채움 `tvBox`), 이름 칸은 내 칸이 판(보관함 포함) 아래, 다른 사람은 위에 판 끝에서 `CHIP_GAP` 띄움(`chipHTML`·`barHTML`·`meBarHTML`·`chipsAt`), 참가한 사람 앞에 보드와 떨어진 진갈색 보관함(홈 10개)에 벽을 세워 둠, 말 점프·벽 날아가기, 누르면 반투명 미리 보기 → [놓기]로 확정, 내 보관함의 벽을 눌러 고르면 살짝 올라오고 벽 모드, 개인 설정 '두 번 눌러 놓기'(`gura-dbltap`), 시작 연출: 로비 카메라→바로 위 카메라·보드 내려앉기와 칸 솟기·보관함과 벽 꽂기·말 떨어지며 목표 줄 긋기·첫 차례 주사위(공통 `firstPick` + `dicepick.js`: 마지막 말의 목표 줄이 끝난 뒤 0.5초 쉬고 → 보드 가운데에 주사위를 던짐(면마다 자리 색, 5·7명은 다시 굴리기 면) → 멈추면 그 자리 말 밑에 고리 + 이름표 켜짐 + 가운데 'OO부터 시작합니다'. 한 번에 끝나면 연출은 약 6~6.5초, 다시 굴릴 때마다 약 1.6초 늘어남. 방 설정 '선 플레이어'를 선택으로 하면 방장이 이름표 메뉴에서 선을 고르고 주사위 없이 약 4초), 대기실은 공통 테이블). 벽 수는 공식 규칙(2명 10개, 4명 5개). WebGL이 없으면 2D 보드(SVG) (카드 없음, 최대 4명, 빠른 모드 없음)
