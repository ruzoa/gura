# 체스 (`games/chess.js`)

> 원래 `CLAUDE.md` 파일 구조 표에 있던 자세한 설명입니다. 이 기능을 바꾸면 이 문서를 고칩니다.

체스 규칙 엔진(순수 함수, 0x88 판: `gen`·`make`·`unmake`·`legal`·`perft`, 캐슬링·앙파상·프로모션, 국면 해시 두 줄, `san`·`fromUci`·`toUci`·`replay`, `endOf`: 체크메이트·스테일메이트·50수·3번 반복(`repKey`: 앙파상을 실제로 할 수 있을 때만 다른 국면)·기물 부족 `deadDraw`는 모두 저절로), 방장 상태 `H.c`는 JSON으로 저장되는 값만(기보 `mv`(uci)·`sn`(SAN)·지금 `fen`·잡은 기물 `cp`·색 `co`(자리→0 백·1 흑)·시계 `rem`·무승부 제안 `dr`), 지금 국면은 기보를 다시 두어 `HC`에 기억. 체스 시계(총 시간 `tm`분 + 추가 시간 `inc`초, 기본 3+2. 시간 초과 패배, 상대가 메이트할 기물이 없으면 무승부 `cantMate`), 선 직접 고르기 `pickfirst`(켜면 방장이 대기실 [선]으로 백을 고름, 끄면 랜덤, 바로 시작하면 색을 바꿈), 무승부 제안(위쪽 내 이름 칸을 누르면 '½ 무승부 제안', 상대에게 '½ 무승부 받기' 단추, 받는 사람이 그냥 두면 없던 일, 한 판에 세 번까지, 봇은 지고 있거나 오래 비슷하면 받음). 봇(`think`): 반복 심화 PVS 알파-베타 + 기억표 + 널 무브 + LMR + 역 퓨틸리티 + 킬러·히스토리 + 정리 탐색(델타), 평가(`evalPos`)는 중반·끝판을 섞은 기물 값·자리 점수 + 폰 구조(겹침·고립·통과 폰) + 비숍 쌍 + 열린 줄 룩 + 움직임 + 킹 앞 폰 방패. 난이도 `LV`: 쉬움 0.15초·2수·흔들림 110·가끔(15%) 얕게 본 수 중 아무거나, 보통 0.6초·5수·흔들림 28·정석, 어려움 1.8초·끝까지·정석(`BOOK`, 12수 반까지). 봇끼리(시간 ¼) 쉬움 0:8 보통, 보통 0:7(1무) 어려움, 새 어려움 8:0 예전 임시 어려움. 방장 화면이 멈추지 않게 같은 파일을 Web Worker로 띄워(`IS_WORKER`면 `self.onmessage`만, 게임 등록 안 함) 기보를 보내고 답을 받아 둠(`botTurn`·`botReply`, `BOTW.pend`: 판이 바뀌었거나 사람이 돌아왔으면 버림, 15초 넘게 답이 없으면 다시, 일꾼이 없으면 바로 계산). 테스트는 `setBotScale`로 생각 시간을 줄임. 화면: 흑을 잡으면 판을 돌려 내 기물이 늘 아래(`flipped`). 3D는 공통 테이블 가운데 원목 틀 + 나무 무늬 칸(`drawBoardTex`, 좌표는 틀에) + 클래식 기물(실물 스탠턴 비율: 키 킹 1 · 퀸 .9 · 비숍 .78 · 나이트 .72 · 룩 .62 · 폰 .52, 받침 반지름 `BR0` 킹 .35 … 폰 .26, 몸통은 곡선 `curve`(캣멀-롬)으로 가늘게·칼라와 받침 턱은 얇고 각지게 `prof`, 먹선 두께는 받침 크기에 비례. 돌림 모양 `profs()` + 장식: 룩 성벽 다섯 토막, 비숍 홈, 퀸 왕관 구슬, 킹 십자, 나이트는 말머리 옆모양(턱·입·코·귀, `knightShape`)을 둥근 턱으로 베개처럼 돌출해 코·귀 쪽으로 얇게 깎고(`kExtrude`) 목 뒤에 톱니 갈기(`maneShape`), 눈·콧구멍·입 선, 받침 위 칼라, 머리 크기 `KNS`(키는 실물 비율 그대로, 가로·두께만 줄임), 내 화면 왼쪽을 보며 상대 쪽으로 조금 `placeRot`), 툰 셰이딩 + 먹선. 대기실 홀로그램 말도 같은 나이트(`G.holoPiece(재질)`을 공통 `frontHoloPiece`가 부름). 카메라는 내 쪽에서 52도로 비스듬히(`PITCH`) 판·기물·잡은 기물이 판 자리에 꽉 차게 거리를 찾고(`ch3Layout`), 잡은 기물은 넓은 화면은 판 옆(내 것 오른쪽 아래·상대 것 왼쪽 위), 좁은 화면은 판 앞뒤에 작게(`graveXZ`). 내 기물을 누르면 살짝 들리고 갈 수 있는 칸에 점·잡을 수 있는 칸에 고리, 칸을 누르면 반투명 기물로 미리 보기(옮기는 기물·잡힐 기물은 숨김) → [두기](두 번 눌러 놓기면 같은 칸 한 번 더), 상대 차례에도 내 차례라고 치고 미리 고를 수 있고 상대가 둔 뒤 안 되면 조용히 지움. 못 움직이는 기물을 누르면 금지 소리 + 체크하거나 핀을 건 상대 기물 칸이 잠깐 빨강(`blockers`). 체크는 킹 칸이 붉게 빛나고 두 음. 프로모션은 안내 줄 옆 기물 단추 넷(퀸이 기본). 마지막 수 노란 칸, 수는 미끄러지듯(나이트는 뛰어오름, 캐슬링은 룩도), 잡힌 기물은 잡은 쪽 옆으로 날아가 작아짐. 위쪽 이름 칸: 색·이름·시간(10초 아래 0.1초, 빨갛게 깜빡임)·잡은 기물 그림·제안 ½. 시작 연출 3.5초: 판 내려앉기 → 계급 순서로 기물이 떨어져 섬(백·흑 같은 박자: 폰 a→h 물결 → 나이트 → 비숍 → 룩 → 퀸 → 킹 혼자 마지막, 더 높이서 '쿵', 소리는 계급이 오를수록 낮고 묵직 `sndLand`, 시각은 `pieceAt`) → 킹이 서면 '○○님이 백으로 먼저 시작합니다'. 바로 시작은 판을 다시 차리지 않고 판 위·옆의 기물을 같은 계급 순서로 처음 자리로 미끄러져 돌려놓음(`regather`: 같은 종류·색 중 가까운 것끼리 짝, 모자라면 떨어뜨림). 색이 바뀌어 판을 돌려 봐야 하면 먼저 기물 묶음(`Ch3.pg`)만 반 바퀴 돌고 좌표 글자는 중간에 바뀜(판 무늬는 대칭이라 그대로). 2D 판(SVG, 기물 그림 `pieceSvg`는 프로모션 단추·잡은 기물에도 씀), 기보 PGN 복사 (최대 2명, 빠른 모드 없음, `tests/chess.cases.js`: perft 6국면·SAN·끝 판정·엔진·봇 대전)
