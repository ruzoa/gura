# 야추다이스 (`games/yahtzee.js`)

> 원래 `CLAUDE.md` 파일 구조 표에 있던 자세한 설명입니다. 이 기능을 바꾸면 이 문서를 고칩니다.

야추다이스 규칙 엔진, 봇, 3D 컵·주사위(자체 물리, 눈은 방장이 정하고 그 눈으로 떨어지게 연출, 떨어진 주사위를 누르면 앞쪽 고정 칸으로·다시 누르면 테이블로, 시작 연출: 로비 카메라→야추 카메라·펠트와 고정 칸·컵에 주사위 담기·펠트 가운데에 첫 차례 주사위(공통 `firstPick` + `dicepick.js`, 한 번에 끝나면 약 5.5초, 멈추면 컵 띠 색·위쪽 차례 표시가 그 자리 색으로 켜지고 가운데 'OO부터 시작합니다'), 바로 시작은 테이블 그대로 게임 주사위만 컵으로 모으고 첫 차례 주사위 약 4초), 점수 종이 (카드 없음, 최대 4명, 빠른 모드 없음, 굴리기 키 `C`를 누르고 있다 떼기). WebGL이 없으면 2D 주사위 칸

## 조작·화면 배치 (2026-10-29)
- **기록하기 버튼 없음**: 점수 칸을 한 번 누르면 미리 보기, 같은 칸을 한 번 더 누르면 기록합니다(Enter도 같은 뜻). `#btnPlay`는 키 입력 연결용으로만 남기고 숨깁니다.
- **굴리기**: 3D에서는 쉬는 컵 위의 투명 버튼(`.yz-cup`)을 누르고 있으면 흔들고 떼면 던집니다(키 `C`도 같음). 점수 종이가 아래로 내려오는 좁은 화면(<820px)에서만 기록하기 버튼 자리(오른쪽 아래)에 굴리기 버튼(`#yzRoll2`)이 있고, 종이가 오른쪽에 오는 넓은 화면은 버튼 없이 컵만 누릅니다. 2D 화면(WebGL 없음)은 예전 굴리기 버튼 그대로.
- **라운드·남은 굴림**: 3D에서는 왼쪽 위 칩에서 빼고, 주사위 고정 칸 줄 바로 아래 가운데(`.yz-info`)에 첫 줄 라운드, 둘째 줄 점 3개로 보입니다(시작 연출 중·게임이 끝난 뒤에는 비움). 2D는 왼쪽 위 칩 그대로.
- 첫 차례 주사위 연출은 그대로 둡니다(삭제하지 않기로 함).
