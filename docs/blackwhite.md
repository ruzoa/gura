# 흑과백 (`games/blackwhite.js`)

2명이 하는 숫자 타일 게임입니다. 원작(더 지니어스 흑과백)에 '0은 8을 잡음' 규칙을 더했습니다.

## 규칙
- 각자 0~8 타일 9개. 짝수(0·2·4·6·8)는 흑, 홀수(1·3·5·7)는 백.
- 한 판: 선이 타일을 엎어 내면 상대는 그 **색만 보고** 엎어 냄 → 큰 수가 1점. **0은 8에게만 이김**(`cmp`).
- 같은 수면 무승부(점수 없음, 선 그대로). 다음 판 선은 이긴 사람. 첫 판 선은 공통 첫 차례 주사위(`G.firstPick`, `pickfirst` 설정 없음 = 늘 무작위).
- 5점 먼저 → 승리. 9판이 끝나면 점수가 높은 쪽 승리, 같으면 무승부(둘 다 1위).
- 제한 시간(`turn`, 10~120초, 기본 30초): 지나면 남은 타일 중 무작위로 냄(패배 아님).
- 봇은 쉬움 하나(`oneBotLv`): 선이면 아무거나, 따라 낼 때는 반쯤 아무거나·반쯤 그 색 수의 절반 넘게 이기는 가장 작은 타일.

## 엔진 (`H.bw`)
- `hand[seat]`: 남은 값, `vo[seat]`: 남은 값을 섞은 순서(낼 때마다 다시 섞음), `pl`: 이번 판에 낸 값, `rec`: `{a: 선, t:[값0,값1], w: 이긴 자리|-1}`, `sc`, `A`(다음 선), `first`(첫 판 선), `gn`(판 번호).
- 단계 `ph`: `lead` → `follow` → `show`(결과 연출 `SHOW_MS` 1.7초, 아무 차례도 아님, 판 결과 기록은 이 단계가 끝날 때) → 다음 판 또는 끝.
- `snap`: 숫자는 자기 것만(`my`, `rec.v`, `pl.v`), 상대 손은 섞은 순서의 색만(`oc`). 관전자는 색만. 끝나면 `ov`(남은 타일 값)와 모든 숫자를 보냄.

## 화면
- 바로 위(90°) 자기 카메라. 아래 줄 = 내 타일(0~8 순서, 숫자 보임), 위 줄 = 상대 타일(엎은 채 색만, 판마다 섞여 다시 놓임), 가운데 = 기록 판(9칸 × 위아래).
- 타일 물건 하나가 손 → 기록 칸으로 미끄러짐(0.43초). 이긴 쪽 기록 타일 둘레에 금색 실선 테두리(0.5초 뒤 한 번 반짝 + 소리), 비기면 양쪽 은색. 내 기록 타일은 숫자가 보이고, 상대 것은 엎은 채.
- 지금 차례인 사람의 다음 빈 기록 칸에 흰 점선 테두리. 이름 칸: 자리 색 점(주사위 면 색) · 이름 · 점수 · 차례면 남은 초(5초 남으면 빨갛게 깜빡).
- 끝나면 기록 칸 왼쪽부터 → 남은 타일 순으로 뒤집혀 숫자 공개. `G.overDelay`로 뒤집기가 끝난 뒤(내 자리 2.2초·관전 3.2초) 결과 창을 띄움(WebGL이 없으면 바로). 결과 창에 기록 글.
- 조작: 내 타일 누르기 = 들기(상대 차례에도), [내기] = 내기, 같은 타일 다시 = 내려놓기(두 번 눌러 놓기면 냄), Esc = 내려놓기.
- 시작 연출: 로비 카메라 → 위, 기록 판 내려앉음, 타일 두 줄에 떨어짐, 1.65초부터 주사위. 바로 시작은 타일만 떨어지고 0.95초부터 주사위.
- WebGL이 없으면 HTML 타일 줄(`.bw-2d`).
- 홀로그램 말: 엎은 흑 타일 + 숫자 7 백 타일(`G.holoPiece`).
