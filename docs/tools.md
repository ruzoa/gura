## `dicepick.js`

첫 차례 주사위: 모양·순서·자세 계산(순수 함수, 화면·소리 없음) + THREE 주사위 만들기(`DicePick.mesh`). `DicePick.plan(인원, 첫 차례, {rolls, seed, dur, durAgain, pause, wait})` → 굴림마다 목표 면·시작/끝 자리·회전·높이표·닿는 소리 시각(`impacts`), `poseAt(e)`(e ms 시점의 자세, 한 변 = 1인 단위, 바닥에 파고들지 않게 가장 낮은 꼭짓점으로 높이를 맞춤), `at(e)`(멈추기 전 -1). 면: 2·3·6명 6면체, 4·8명 8면체(색마다 면 수 같음, 이웃한 면은 다른 색), 5명 6면체·7명 8면체는 남는 한 면이 '다시 굴리기'(검은 원 + 빨간 ↻). `pickRolls(n)`은 방장이 던질 횟수를 뽑음(다시 굴림 확률 5명 1/6·7명 1/8, 최대 `MAXR`), `totalFor(rolls)`는 연출 길이(첫 굴림 + (횟수-1)×(쉼 + 다시 굴림) + 멈춘 뒤 안내), rolls<0은 방장이 고른 선(굴리지 않음). 값은 `DicePick.DEF` 한 곳(테스트룸에서 맞춘 값: 첫 굴림 1.8초, 다시 굴림 1.3초, 쉼 0.26초, 안내 1.1초). 자리 색 `DicePick.SEAT_COL`(8색). 모양은 야추다이스 주사위와 같은 몸통(크림색·둥근 모서리·먹색 외곽선)에 면마다 자리 색 원 하나: 값은 `LOOK` 한 곳(6면체 둥글기 .132·원 지름 = 한 변의 70%, 8면체 둥글기 = 한 변의 8%·원 = 내접원의 80%, 원은 평평한 곳 안에만). 바닥 높이는 둥근 모양 기준(`inner` + `r`). 게임 안에서는 공통 `toon` 재질, 테스트룸에는 없어서 기본 재질이라 명암이 조금 다름. 쿼리도(보드 가운데)·야추다이스(펠트 가운데)·포커(탁자 가운데)에 연결됨. 같은 씨앗이면 모두 같은 굴림

## `lab.html`

연출 테스트룸 (메인에 링크 없음, 배포 주소 `/gura/lab.html`, 위쪽 링크로 `lab-icon.html`·`lab-hand.html`·`lab-poker.html`·`lab-doll.html`·`lab-fan.html`과 오감). 첫 차례 주사위: 실제 `dicepick.js`로 3D 주사위를 굴려 봄. 인원(2~8)·첫 차례·던진 횟수(자동 = 방장 뽑기, 1~3번)·카메라(앉은 눈 37°, 바로 위)·화면 비율, 슬라이더(첫 굴림 길이, 다시 굴림 길이, 굴림 사이 쉼, 멈춘 뒤 안내, 주사위 크기), 면 배치와 연출 길이 표시, [다시 보기], [값 복사]. 마지막 값은 `gura-lab-dice`에 저장

## `lab-doll.html`

테스트룸 · 플레이어 인형. 의자(나무 기둥) 위에 얹을 인형 후보를 나란히 세워 봄: 나무 말, 동물 나무 인형(토끼·곰·고양이·여우, 몸통은 같고 귀·꼬리만 다름), 오뚝이, 종이 스탠디, 물건(화분), 봇(통나무 + 동물 얼굴 종이 + 투명 테이프). 인형을 문지르면 고른 색으로 칠해짐(누른 자리의 겉면 좌표에 붓 자국, 부품마다 작은 그림 한 장, 얼굴은 그 위에 덧그림), 빈 곳을 끌면 돌려 보기. 표정(웃음·놀람·시무룩)·움직임(폴짝·끄덕·갸웃), 칠한 그림을 보낼 때 크기(PNG) 표시. 키 슬라이더(몸통만 길게, 바꾸면 인형을 다시 만들어 칠이 처음으로)와 탁자 높이 판(의자 위 1.25, 반투명, 숨기기 가능)으로 탁자 위로 얼마나 올라오는지 봄. 먹선 테두리는 부품을 통째로 키우지 않고 겉면에서 같은 두께만큼 밀어낸 껍질(`hullGeo`)이라 두께가 고름. 게임 코드와 따로 도는 시험용이고 정해지면 `core/`로 옮김.

## `lab-fan.html`

테스트룸 · 카드 든 인형. 고른 화면 크기(휴대폰 세로·휴대폰 가로·PC)의 게임(`index.html`)을 iframe으로 줄여 보여 주고, 혼자(오프라인) 구라! 탁자를 고른 인원(2~6명, 나머지는 봇)으로 바로 시작. 봇 자리 모습은 인형(나무 말·동물·오뚝이 여러 가지)·통나무·섞어서: 화면에 가는 상태(`snapFor`)에서만 봇 표시를 떼고 인형 값을 붙이고 엔진의 봇은 그대로 둠. 상대 손패 '지금(탁자 위 더미)'·'부채꼴', 손 없음·공·장갑, 슬라이더(카드 크기·높이·앞뒤·기울기·펼침·펼침 상한·손 위치)는 `OPP_FAN`으로 바로 바뀜(기본값은 구라!에 넣은 값, '지금'·'부채꼴'은 `OPP_FAN.on`으로 강제). 최대 장수는 사용자가 없애서 뺌. [멈춤]은 구라! 엔진의 `tick`을 쉬게 해 봇·제한 시간을 멈춤(풀면 지난 제한 시간이 바로 지남). [값 복사]는 고른 값을 글로. 마지막 값은 `gura-lab-fan`에 저장

## `lab-poker.html`

테스트룸 · 포커 카메라. 고른 화면 크기(휴대폰 세로·작은 휴대폰·태블릿 세로·휴대폰 가로·PC)의 게임(`index.html`)을 iframe으로 줄여 보여 주고, 혼자(오프라인) 포커 탁자를 차려 고른 인원(2~8명, 나머지는 봇)으로 바로 시작. 각도·화각(초점 거리 mm, 클수록 망원)·거리·위아래(카메라를 화면 위아래로 옮김) 슬라이더는 `GAMES.poker.labCam`으로 바로 바뀜(세로 화면에만 씀). [값 복사]는 `PK_EL=…,PK_FL=…,PK_D=…,PK_Y=…`. 마지막 값은 `gura-lab-poker`에 저장  (포커 카메라가 공통 카메라와 같아지면서 `GAMES.poker.labCam`은 없어졌고 각도·화각 슬라이더는 더 쓰지 않음. 화면 크기별 미리 보기와 인원 고르기만 씀)

## `lab-icon.html`

테스트룸 · 아이콘 찍기. 게임 속 탁자(툰 셰이딩·원목 상판·받침·펠트, `core/table3d.js`의 그림 코드를 옮겨 둠: 게임 쪽 탁자를 바꾸면 여기도 맞춤)를 들판에서 찍어 `icon-512.png`, `icon-192.png`, `apple-touch-icon-180.png`, `icon-maskable-512.png`(안드로이드 안전 영역에 맞게 0.8배), `og-image.png`(링크 미리보기 1200×630)로 저장. 안개는 카메라 거리에 맞춰 탁자 뒤 '안개 거리'만큼 떨어진 곳부터(망원에서도 탁자가 가려지지 않게, 기본 5, 100은 안개 없음). 방향·각도·크기·원근감·다리 길이(게임은 1)·윤곽선(게임은 1), 하늘(진짜 하늘: 위로 갈수록 짙은 파랑 그라데이션 + 흰 구름, 또는 게임 그대로 단색), 풀·나무·그림자·구름 그림자·펠트 켜고 끄기, 안전 영역 점선 원, 아이폰·안드로이드·작은 크기 미리보기. 값은 `gura-lab-icon`에 저장

## `tests/dicepick.test.js`
