# 숫자야구 (`games/baseball.js`)

겹치지 않는 3~5자리 숫자(기본 4, 0은 맨 앞도 가능)를 추리합니다. 자리까지 맞으면 S, 숫자만 맞으면 B, 없으면 OUT.

## 게임 모드 (`md`)
- **0 혼자**(1명): 10번 안에 찾기. 시간제한 없음. 최대 인원 1(`maxOf`, `minN`).
- **1 맞대결**(2명): 각자 비밀 숫자를 정하고(`set`, 시간이 지나면 무작위) 매 턴 동시 공격. 낸 수는 둘 다 낼 때까지 숨김(`pg`, 상대 `snap`에 없음). 시간이 지나면 못 낸 사람만 건너뜀. 둘 다 맞히면 무승부. 20턴(`VS_MAX`)·3턴 연속 둘 다 안 내면 무승부.
- **2 경주**(2~6명): 정답 하나를 차례로 부르고 결과 공유. 이미 나온 수는 금지. 첫 차례는 공통 주사위(`firstPick`는 경주일 때만 참), 다음 판은 선을 넘김.
- **버저**(경주): 결과 공개 중(`rv`)이 아니면 언제든, 자기 차례에도 가능. 0.3초 눌러야 작동, 방장은 0.12초 늦게 보냄(`HOST_LAG`). 게임이 멈추고(`buzz`, 남은 제한 시간은 보관) 10초 안에 입력. 맞히면 승리, 틀리거나 시간 초과면 사망, 틀린 수의 결과는 공개. 마지막 한 명이면 승리. 일반 부르기는 틀려도 죽지 않음.
- 제한 시간 기본 45초(`turn`, 15~120초), 넘기면 차례만 넘어감. 경주는 모두가 세 바퀴 안 부르면 무승부.

## 엔진 (`H.nb`)
- 단계 `ph`: `set`(맞대결만) → `guess` ↔ `buzz` → `rv`(플립 공개, `RV_MS`, 맞히면 `WIN_RV`) → `done`.
- `rec` 한 줄 `{n,s,g,S,B,x}`: g가 null이면 시간 초과, x는 버저. 기록 글은 공개가 끝난 뒤 `addLog`(`logQ`).
- `snap`: 정답은 끝날 때만(`sec`, 맞대결은 배열), 맞대결 내 비밀 `my`, 낸 수 `mg`, 냈는지 `dn`, `s.t`는 사람마다 따로.
- 봇 후보(`poolFor`)는 `H`에 저장하지 않고 기록에서 다시 만듦(저장 크기·방장 이양). 쉬움은 30%로 정보를 놓치고 후보가 3개 이하면 가끔 버저, 보통은 후보 무작위, 어려움은 표본으로 남는 후보가 가장 적은 수. 후보가 하나면 사람보다 2~4초 늦게 버저.

## 화면
- 앉은 카메라(모든 게임과 같음) 그대로. 고개 돌리기는 끔(`G.noView`). 앞에서 뒤로 자판 두 줄(나무 띠) · 램프 줄 · 경첩으로 세운 플립 판과 옆 칸 · 그 뒤 맞은편으로 깔리는 영수증. 물건 크기는 모든 기기에서 같고, 휴대폰은 자판이 폭을 채움.
- 시작 연출: 대기실 자판이 틈으로 들어감(공통) → 공통 디스플레이 자리에서 플립 판이 넘겨받아(`G.ownBoard`, 공통 판은 숨김) 앞으로 나오며 넓어지고 플립이 촤르륵 → 틈이 열리고 큰 자판·램프·옆 칸(버저)이 올라옴. 대기실로 돌아가면 거꾸로(`pose(morph,rise)`). 바로 시작은 장치를 그대로 둠.
- 옆 칸: 혼자 남은 횟수, 맞대결 내 비밀 숫자(누르면 가리기)·정할 때는 주사위. 경주는 옆 칸 대신 판 오른쪽 뒤의 버저 돔.
- 누르기는 실제 물건을 맞힘(`hitAt`, Raycaster).
- 플립: 입력은 바로, 결과는 한 칸씩 → 다 맞히면 전체가 촤르륵 + 홈런 소리. 다른 사람 버저 입력 중에는 숫자 칸이 돎. 끝나면 못 찾은 정답이 뜸.
- 영수증: 공개가 끝난 뒤 찍힘. 12줄이 넘으면 오래된 줄이 사라지고, 누르면 2D 영수증(전체). 맞대결은 한 턴이 한 줄(왼쪽 내 것). `G.rcOwn`.
- 램프: 켜짐 = 가능, 꺼짐 = 제외. 내 화면에만, `gura-nb-lamp`에 그 판 동안 저장. 끄면 같은 숫자 키가 어두워지지만 입력은 됨.
- 키보드: 숫자 입력, Shift+숫자 램프, Backspace, Enter, Space 누르고 있기 = 버저.
- WebGL이 없으면 HTML(`.nb-2d`).
