# 대부호 (`games/president.js`)

> 원래 `CLAUDE.md` 파일 구조 표에 있던 자세한 설명입니다. 이 기능을 바꾸면 이 문서를 고칩니다.

대부호 규칙 엔진, 봇, 카드 모양, 화면 표시. 계급 카드 교환 연출(카드 나누기 뒤 `dealExtra` 2.1초: 대빈민·빈민의 강한 카드가 날아가고 약한 카드가 돌아옴. 누가 누구에게 몇 장인지는 모두에게 뒷면으로, 앞면은 당사자만. 받을 카드 자리는 손패에서 비워 뒀다가 도착하면 채우고 노란 테두리)

## 라운드·점수·계급 유지 (2026-10-30)

- **라운드 설정**: 탁자 설정 '라운드'(1~20, 기본 3, `cfg.rounds`). 한 판이 끝날 때마다 계급 점수를 이름으로 쌓습니다(`H.scores`). 점수는 계급마다 정해짐(`RANK_PTS`): 대빈민 0 · 빈민 1 · 평민 2 · 부호 3 · 대부호 4 (4명이면 4·3·1·0, 3명이면 4·2·0, 평민이 여럿이면 모두 2점). 정한 라운드를 마치면(`H.setDone`) 결과 화면에 최종 순위가 나옵니다. 점수 합계순, 같으면 마지막 판 계급이 높은 사람이 앞섬(`finalOrder`).
- **도중 참가 불가**: 첫 판이 끝나고 정한 라운드를 다 마치기 전에는 관전자가 다음 판에 참가할 수 없습니다(`G.joinLocked`, 스냅샷 `nj`). 마지막 라운드가 끝나면 다시 참가할 수 있습니다. 게임 중 위쪽에 `n / N 라운드` 배지.
- **계급·점수가 이어지는 때**: 결과 화면의 '바로 시작'(다시 하기), 끊겼다가 다시 들어온 사람(`H.members`에 남아 있으면 유지). 정한 라운드를 마친 뒤 바로 시작하면 점수·라운드만 0으로 돌아가고 계급은 이어집니다.
- **초기화되는 때**: 결과 화면에서 '대기실'로 갈 때(`panelAct`의 `again`이 `clearSet()`을 부른 뒤 공통 코드가 대기실로 보냄), 탁자를 나간 사람 본인(`dropGone()`, 대기실·결과 화면 스냅샷마다), 게임을 바꿀 때(`engine.reset`), '계급 초기화' 버튼.
- **배경음악**: 대기실(`V.st==='wait'`)에서는 대부호 전용 곡을 멈추고 공통 배경음악이 나옵니다(`G.ownBgm`, `BG.watch`). 게임이 시작되면 공통 곡이 멈추고 대부호 곡이 나옵니다.
