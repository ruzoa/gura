# 포커 (`games/poker.js`)

> 이 기능을 바꾸면 이 문서를 고칩니다.

텍사스 홀덤, 노 리밋. 규칙 엔진·족보·쉬움 봇·화면이 한 파일에 있습니다 (`tests/poker.cases.js`).

## 규칙
- 모두 같은 칩(`chips`, 기본 1000)으로 시작해 정한 판 수(`rounds`, 3~50, 기본 10)를 마치면 칩 순서로 순위(같으면 같은 순위). 칩을 다 잃으면 그 판이 끝날 때 탈락(그 판을 적은 칩으로 시작한 사람이 아래 순위). 둘보다 적게 남으면 바로 끝.
- 블라인드: 스몰 `sb`(기본 10), 빅은 두 배. `up`판마다 두 배(0이면 그대로). 버튼 왼쪽이 스몰·그다음 빅, 둘이서는 버튼이 스몰이고 프리플랍에 먼저·플랍부터 나중.
- 첫 딜러 버튼은 공통 주사위(`G.firstPick`, `G.intro`: 탁자 가운데에 던지고, 멈추면 그 자리에 자리 색 링 + 가운데 '○○ 님이 첫 딜러입니다'), '첫 딜러'를 선택(`pickfirst`)으로 하면 방장이 이름표 메뉴에서 고름. 그 뒤 판마다 왼쪽(남은 사람)으로.
- 한 판: 블라인드 → 카드 2장(스몰부터, `beginDeal`로 그동안 멈춤) → 프리플랍·플랍(3장)·턴·리버 베팅(공용 카드 전에 한 장씩 버림) → 쇼다운 → 정산 → 다음 판. 모두 폴드하면 남은 사람이 카드를 보이지 않고 가져감.
- 행동: `{t:'fold'}`, `{t:'call'}`(체크·콜), `{t:'raise',a:목표}`(이번 베팅 차례에 건 칩 합계 기준, 최소보다 적으면 최소로) 또는 `{t:'raise',all:1}`(올인). 최소 레이즈 = 바로 앞에서 올린 만큼(처음은 빅 블라인드). 최소보다 적은 올인은 이미 행동한 사람에게 레이즈를 다시 열지 않음(`ro`).
- 더 걸 사람이 없으면(행동할 수 있는 사람이 0명, 또는 1명이고 이미 맞춤) 모두의 카드를 펼치고(`open`) 남은 공용 카드를 한 장씩 사이를 두고 펼침.
- 팟 나누기(`splitPots`): 낸 칩(`tot`)의 층마다 그 층까지 낸 사람끼리(사이드 팟). 혼자인 층은 돌려받음(`ret`). 모든 금액은 10(`U`) 단위, 나누고 남는 칩은 버튼 왼쪽부터 10씩.
- 시간 초과: 체크할 수 있으면 체크, 아니면 폴드. 항복·탈주는 폴드하고 탈락(남은 칩은 그대로 두고 순위만), 한 명만 남으면 팟을 주고 끝.

## 상태 (`H.pk`)
`ch` 앞에 남은 칩(건 칩은 뺌), `bet` 이번 베팅 차례에 건 칩, `tot` 이번 판에 낸 칩(팟 = 합). 정산하면 팟은 `rs`(`won`·`pot`·`pots`·`show`·`best`)로 옮기고 `tot`는 비움(칩 총합 = `ch`+`tot`). `st` 0 겨루는 중·1 폴드·2 올인·3 이번 판에 없음. `sr` 0~3 = 프리플랍~리버. `ph`: intro → deal → bet ⇄ run(칩 모으기·공용 카드) → show → (다음 판 deal | end).
- `hand`는 [0]만 두고 진짜 카드는 `hc`·`bd`. `snap`은 받는 사람 자기 카드만 보내고 남의 카드는 -1(쇼다운 `rs.show`·올인 `open`만 펼침), 덱은 보내지 않음. 관전자는 펼친 카드만.

## 족보
`eval5`: 등급 × 15⁵ + 비교할 숫자들(높은 것부터) → 숫자 하나로 비교. `best`(5~7장, 이긴 5장 `five`도 돌려줌), 봇용 빠른 `score7`(숫자·무늬를 세어 바로 계산, `best(cs).v`와 같은 값을 테스트로 대조). 이름: 하이 카드 · 원 페어 · 투 페어 · 트리플 · 스트레이트 · 플러시 · 풀 하우스 · 포카드 · 스트레이트 플러시(A 높으면 로열 플러시).

## 봇 (쉬움만)
프리플랍은 두 장 점수(`preScore`, Chen 공식 비슷), 플랍부터는 남은 상대 수만큼 끝까지 펼쳐 본 승률(`equity`, 110~180번)을 팟 오즈와 견줌. 무작위로 가끔 따라가거나 블러핑. 체크할 수 있으면 폴드하지 않음. 대기실에서 난이도를 고르지 않음(`G.oneBotLv`: 레벨 단추·메뉴를 숨기고 '봇'으로만 표시).

## 화면
- 천 확대: 대기실에서 게임으로 들어오면 펠트(천)만 0.9초에 걸쳐 반지름 3.15 → 4.025(탁자 4.9와의 차이 절반)로 커짐(블랙잭과 같음, `useFelt`·`feltFrame`, 카드·칩 자리는 그대로). 그림은 커진 크기 기준으로 한 번 그리고 커지는 동안 가운데만 잘라 써서(`repeat`·`offset`) 무늬는 제자리, 가장자리 테두리 선만 펠트 끝을 따라감(`feltRims`). 바로 시작은 커진 그대로, 대기실로 돌아가면 원래 크기.
- 3D: 둥근 탁자에 펠트 그림만 바꿈(공용 카드 다섯 칸 테두리, 글자 없음). 공용 카드(`O`)는 탁자 정중앙, 그 바로 맞은편에 덱, 내 쪽에 팟(`POT`)·내 베팅 칸. 칩 더미(10·50·100·500)는 펠트 밖 나무 띠 위 내 앞(`BANK_Z` 4.3, 커진 펠트 바깥: 기둥이 높아도 화면에서 베팅할 칩 공간을 가리지 않게), 누르는 자리는 기둥마다 맨 위 칩(`topChipAt`: 맨 위 칩 높이의 평면에서 그 칩 자리 + 화면 위쪽으로 조금 여유). 다른 사람은 나를 아래(0°)로 두고 탁자 둘레를 360°/인원으로 똑같이 나눈 자리(`thetas`, 공통 `seatAngle`)에 앉은 순서대로 작은 카드 두 장(모든 자리의 카드는 겹치지 않게 옆으로 나란히, 카드 위쪽이 탁자 중심을 향함.), 베팅 칩은 자리에서 가운데 쪽으로(공용 카드 칸에 걸치면 위아래로 비킴 `offBoard`), 자리는 화면 비율과 상관없이 고정(가로 반지름 `RX` 2.95, 카드 두 장 간격도 같음): 좁은 화면은 양옆 자리가 잘리고 이름표는 화면 끝에 붙음. 관전 중이면 내 앞자리를 비움.
- 내 카드: 2D 손패 없이 탁자 위 내 자리(`MY`)에 엎어 둠. 마우스를 올리거나(`PEEK.hover`) 손가락을 대고 있으면 내 쪽 왼쪽 귀퉁이(앞면 오른쪽 아래, 거꾸로 그린 숫자)만 둥글게 말려 올라가 숫자가 보임(`bendable`·`bendCard`: 카드 판을 8×12로 나눠 귀퉁이에서 `PEEK_L` 안쪽을 말아 올림, 0.2초). 그동안 카드 위 공중에 무늬와 숫자가 떠 있음(`#pkPeek`, 사용자가 바란 예외라 '카드 위에 글자 없음'과 다름). 쇼다운·올인으로 펼치면(`myShown`) 앞면으로 뒤집고, 폴드하면 다른 사람처럼 덱 쪽으로 사라짐. 내 이름표(왼쪽 아래)에는 이모티콘·닉네임만 있고 칩·베팅·족보 글은 없음.
- 카메라: 자기 카메라 없이 공통 카메라(`T.cam`)로 그림(37°, 크기 맞춤·고개 돌리기·고정 버튼 모두 공통 코드). 이름표·누르기는 `CAM()`(= `T.cam`). 대기실도 같음.
- 카드 움직임은 블랙잭과 같은 직접 그림(`cardStep`). 나누기는 스몰부터 엔진과 같은 순서, 공용 카드는 모인 칩이 팟에 닿은 뒤(`COLLECT_MS`) 한 장씩. 폴드한 카드는 덱 쪽으로 가서 사라지고(내 카드는 2D 손패에서 흐리게), 사라진 카드도 목록에 남겨(`gone`) 다음 상태에서 덱에서 다시 만들지 않음. 쇼다운에서 펼친 다른 사람 카드는 크게 안쪽으로, 이긴 5장은 들어 올리고 금색 테두리(`glow`).
- 칩: 베팅 차례가 끝나면 베팅 칩이 팟으로 날아가고 도착하면 팟 기둥이 커짐, 정산은 카드를 펼친 뒤 팟이 이긴 사람에게(나누면 나눠서). 이름표의 칩은 팟이 도착한 뒤 늘어남(`shownCh`).
- 버튼 줄(공통 `#actions`: 폴드 · 체크/`콜 N`(콜할 금액은 버튼 글자) · 레이즈 목표): 3D에서는 내 칩 더미 바로 위(`actFrame`: 칩 기둥 12개 높이를 화면에 옮긴 고정 자리에 버튼 아래 끝, `#stage.pk3`의 `--pkAx`·`--pkAy`), 내 차례에만 보임(`.pkoff`, 자리는 그대로). WebGL이 없으면 공통 구석 자리.
- 손짓(버튼과 함께 씀. `gestDown`·`gestMove`·`gestUp`, 누른 자리는 `zoneAt`: card·bet·bank·table): 내 카드를 위(탁자 가운데 쪽)로 `FOLD_DZ` 넘게 밀면 폴드. 내 앞 펠트를 두 번 두드리면(`DBL_MS`) 체크(콜할 칩이 있으면 금지 소리), 두드린 자리에 고리가 퍼짐(`knock`). **베팅할 칩 공간**(`PEND`, 내 카드와 칩 더미 사이)의 칩을 앞으로 `PUSH_DZ` 넘게 밀면 올린 칩이 콜할 만큼보다 많으면 레이즈(최소보다 적으면 금지 소리), 아니면(올린 칩이 없어도) 콜. 내 칩 더미를 누르면 칩 하나가 베팅할 칩 공간으로, 그 공간을 누르면 마지막 칩이 돌아옴. 밀어서 보낸 칩은 제자리로 돌아오지 않고 민 자리에 머물다가 행동이 받아들여지면 **베팅한 칩 공간**(`MYBET`, 건 칩)으로 날아가 합쳐짐(이번 베팅 차례가 끝났으면 팟으로, `settlePend`). 내가 보내지 않은 행동(시간 초과로 체크·폴드)이거나 칩을 내지 않은 행동(폴드)이면 올려 둔 칩은 칩 더미로 돌아감(`V3.sent`). 건 칩은 누르거나 밀 수 없음. 끌던 물건은 놓으면 0.18초에 제자리로(`gestDz`, 밀어서 보낸 칩은 예외 `V3.pend.hold`). 키는 그대로: Q 폴드, Space 체크·콜, F 레이즈, ↑ 빅 블라인드만큼 올리기·↓ 마지막 칩 내리기(블랙잭과 같은 키 이름 `bjUp`·`bjDown`), Z 올인.
- 차례 시간: 지금 차례인 사람의 베팅 칸 둘레 고리(줄어듦, 1/4 남으면 빨강, 내 차례는 베팅할 칩 공간 둘레). 내 차례면 베팅할 칩 공간에 금색 점선 고리가 숨 쉬듯 밝아짐(`pendRing`). 자리 가장자리 고리는 숨김.
- 내 칩 숫자(`numsFrame`, `#pkNums`): 칩 더미 아래에 남은 칩(`bankAmt`), 베팅할 칩 공간 오른쪽에 올려 둔 칩. 칩이 떠나고 도착하는 때에 맞춰 바뀜.
- 이름표: 그 사람 카드 바로 위로 옮김(매 프레임, 겹치면 위로 비킴). 둘째 줄은 마지막 행동(체크·콜·레이즈·올인·폴드), 쇼다운이면 족보와 받은 칩. 폴드하면 흐리게.
- 딜러 버튼(D 원판)은 그 사람 카드 옆, 판이 바뀌면 미끄러져 옮김. 판 시작에 `3 / 10판`(블라인드가 오르면 함께) 잠깐.
- WebGL이 없으면 2D 줄 목록(`#pk2d`)과 2D 칩 버튼(`#pkBet`).
