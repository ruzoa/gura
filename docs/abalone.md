# 아발론 (`games/abalone.js`)

2명이 구슬을 밀어 판 밖으로 떨어뜨리는 추상전략 게임입니다. 화면 틀은 동물장기·픽셀을 따릅니다(탑뷰, 체스 시계). 이 기능을 바꾸면 이 문서를 고칩니다.

## 규칙 (2026-11-04 사용자와 확정)

- 판: 한 변 5칸의 육각형 61칸, 구슬 14개씩, 상대 구슬 6개를 떨어뜨리면 승리.
- 한 수: 일직선으로 붙은 내 구슬 1~3개를 한 칸. 줄 방향 또는 옆으로(옆은 가는 칸이 모두 비어야 함).
- 밀기: 줄 방향으로만, 내 구슬이 더 많을 때(2:1, 3:1, 3:2). 상대 줄 바로 뒤에 내 구슬이 있으면 불가. 내 구슬은 판 밖으로 못 나감.
- 시작 배치(설정 `lay`): 표준·벨기안 데이지·독일 데이지. 기본 표준. 홀로그램 모드 줄은 표준·벨기안·독일.
- 봇: 쉬움·보통·어려움 3단계(대기실 이름표 메뉴). 어려움은 수당 1초(2026-11-04 사용자와 정함).

## Claude가 정한 값 (바꿀 수 있음)

- 시계 10분 + 5초(총 시간 + 추가 시간, 시간을 다 쓰면 패배).
- 같은 국면 3번 무승부. 구슬이 안 떨어진 채 60수(두 사람 합계)면 끝, 더 많이 밀어낸 사람 승리, 같으면 무승부.
- 둘 수 있는 수가 없으면 패배(실제로는 거의 안 나옴). 흑 = 선. 첫 판은 공통 주사위 또는 방장 선택, 바로 시작은 선·후 바꿈.

## 엔진

- 칸 번호는 위 줄 왼쪽부터 0~60, `NB[칸][방향]`(없으면 -1). 방향 0 동, 1 남동, 2 남서, 3 서, 4 북서, 5 북동. `b[칸]` 0 빈 칸, 1 흑, 2 백. 색 번호는 0 흑, 1 백.
- 방장 상태 `H.c`: `R`, `lay`, `A`(선 자리), `co`(자리별 색), `b`, `mv`(기보 문자열), `lm`(`c` 구슬, `d`, `p` 밀린 구슬, `off` 떨어진 칸), `out`(색별 떨어진 수), `np`(안 떨어진 수), `rp`(국면 횟수), 시계 값은 동물장기와 같음.
- `tryMove`가 규칙 한 곳. `arrowsOf`는 방향별로 누를 칸을 고름(옆으로 미는 수는 이웃 방향과 겹치지 않는 끝 칸).
- 쉬움 봇(`botPick`): 떨어뜨리는 수·밀기·가운데로 가는 수를 좋아하고 무작위를 섞음. 내 구슬이 떨어질 자리는 가끔만 살핌.
- 보통·어려움 봇(`botSearch`): 알파-베타 탐색. 보통은 2수까지(0.22초 한도), 어려움은 1초 안에서 한 수씩 더 깊이. 점수는 구슬 수 > 가운데 > 뭉침(`AI`, `LEVEL`). 같은 국면 세 번째가 되는 수는 0점(앞서면 피함), 두 번째도 감점, 60수 판정을 내다봄.
- 일꾼: 보통·어려움은 Web Worker(같은 파일)가 생각(`BOTW`, 없으면 바로 계산). 답이 6초 안에 안 오면 다시 생각. `legal`은 봇이 자주 불러 `tryMove`를 거치지 않고 바로 세며, 결과가 같은지 테스트로 확인.

## 화면

- 카메라: 바로 위(`tvBox`). 백은 판(`P3.root`)만 180도 돌려 내 구슬이 아래로 옴. 카메라를 돌리면 탁자와 영수증까지 뒤집히므로 돌리지 않음. 누른 곳 좌표는 `worldAt`이 되돌림.
- 조작: 내 구슬을 누르면 고름, 같은 줄의 구슬을 더 누르면 늘어남(하나 건너뛰면 사이 구슬도), 끌어서 고르기도 됨. 갈 수 있는 칸에 화살표. 화살표를 누르거나 고른 구슬을 그 방향으로 밀면 미리 보기(구슬이 민 뒤 자리로 움직임) → [두기]. 두 번 눌러 놓기면 같은 화살표를 다시 눌러 바로 둠. 빈 곳·Esc는 취소.
- 떨어진 구슬: 판 끝 도랑으로 간 뒤 포물선으로 받침에 내려앉음. 받침은 판 위·아래 끝 여섯 칸, 내가 밀어낸 구슬은 내 쪽. 개수가 점수라 3D 화면에는 글자 없음.
- 시작 연출: 로비 카메라 → 위, 판 낙하, 구슬이 위 줄부터 떨어짐, 주사위. 바로 시작은 구슬만 다시.
- WebGL이 없으면 2D 판(SVG), 끌기 없이 누르기, 이름 칸에 `n/6`.
- 홀로그램 말: 육각 판과 구슬 넷(`G.holoPiece`).

## 테스트

`tests/abalone.cases.js`: 판 구조, 칸 이름, 세 배치(14개·대칭), 표준 시작 수 44수, 줄 판정, 밀기(2:1, 3:1, 3:2, 금지 경우), 옆으로 옮기기, 화살표, 봇, 차례·잘못된 수, 6개 승리, 시간 초과, 추가 시간, 반복 무승부, 60수 판정, 항복, 바로 시작, 봇끼리 끝까지, 보통·어려움(이기는 수, 판 보존, 무승부 피하기, 어려움이 쉬움을 이김), `legal`과 `tryMove` 일치. 공통 탈주 테스트에 포함.
