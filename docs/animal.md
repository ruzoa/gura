# 동물장기 (`games/animal.js`)

2명이 3×4 판에서 말 네 개로 하는 게임입니다. 화면 틀(이름 칸·시계·탑뷰 카메라·미리 고르기)은 장기(`docs/janggi.md`)를 따릅니다. 이 기능을 바꾸면 이 문서를 고칩니다.

## 규칙 (사용자와 정한 것, 2026-11-02)

- 판 가로 3 × 세로 4. 각자 자기 쪽 끝 줄 왼쪽부터 코끼리·사자·기린, 사자 앞에 병아리.
- 움직임(한 칸): 코끼리 대각선, 기린 앞뒤·옆, 사자 모든 방향, 병아리 앞. 병아리가 상대 끝 줄에 닿으면 닭(앞·앞 대각선·옆·뒤, 뒤 대각선 못 감).
- 포로: 잡은 말은 내 것(닭은 병아리로). 내 차례에 빈 칸 아무 곳에 놓기 = 한 수. 놓은 병아리는 끝 줄이어도 닭이 아님(그 자리에선 못 움직임).
- 승리: 사자를 잡음(`lion`), 또는 내 사자가 상대 끝 줄에 닿았을 때 상대 말이 그 칸을 노리지 않음(`try`). 노리고 있으면 계속하고, 상대가 다음 수에 잡지 못하면 그때 승리(`judge`의 순서: 사자 잡음 → 끝 줄 상대 사자가 살아남음 → 내 사자 도착).
- **잡힐 자리로 가는 수도 둘 수 있음, 표시 없음**(사용자 결정). 지금 노려지는 내 사자 밑에만 붉은 빛(`att`).
- 같은 국면(판·포로·차례) 3번 → 무승부(`rep`). 둘 수 있는 수가 없으면 패배(`stuck`). 봇끼리만 앉은 판은 300수(반 수)에서 무승부(`long`).
- 시계: 총 시간 + 추가 시간(기본 3분 + 2초, 정한 값). 시간 초과 패배.
- 선: 첫 판은 공통 첫 차례 주사위(`pickfirst` 선택이면 방장이 고름), 바로 시작은 선·후를 바꾸고 주사위 없이 알림(`H.dzLast`).

## 십이장기 모드 (2026-11-02 사용자와 정함)

- 설정 판자 '게임 모드' 플립 `동물장기 / 십이장기`(`cfg.md`, 2D 창은 '십이장기' 스위치), 홀로그램 모드 줄도 같은 이름(`G.modeLabel`).
- 말: 사자 → 왕(王), 기린 → 장(將), 코끼리 → 상(相), 병아리 → 자(子), 닭 → 후(侯). **움직임·처음 배치는 같음**(왼쪽부터 상·왕·장, 왕 앞에 자). 타일은 한자만(장기와 같은 글꼴, 자리 색 글씨·테두리, 방향 점은 그대로).
- 포로는 상대 진영(상대 끝 줄 3칸)에 놓을 수 없음(`gen`). 놓을 칸 점이 그 줄에는 안 뜨고, 누르면 금지 소리.
- 왕이 상대 진영에 들어가면 노려지지 않아도 상대에게 한 수를 주고, 그 수에 잡히지 않으면 승리(`judge`·`search`에서 바로 이기는 판정을 `p.md`면 뺌). 이기고 지는 판은 동물장기와 같고 승리가 뜨는 시점만 다름. 버티는 동안 왕 밑에 금빛(`holdSq`).
- 엔진은 국면에 `md`를 들고 다님(`newPos(md)`·`startPos(md)`·`replay(mv,md)`), 방장 상태 `H.c.md`, 스냅샷 `s.c.md`. 진행 기록·결과의 말 이름도 십이장기 이름(`nmOf`).

## 엔진

- 판 `Int8Array(12)`, 칸 = `y*3+x`(y 0 = 선 쪽 끝 줄). 말 1 병아리 2 코끼리 3 기린 4 사자 5 닭, 후는 +8. 포로 `hd[색][말]`(1~3).
- 수 `f|t<<4`: f 0~11 판, 12+말 = 포로 놓기. 글자 `fftt`. 해시는 판 + 포로(색·말·몇 번째) + 차례.
- 방장 상태 `H.c`: `A`(선 자리), `co`(자리별 색), `mv`(기보), `lm`, `att`, `rem`, `since`, `mv_`, `res`(`w`, `why`). 국면은 기보를 다시 두어 만듦(`replay`).
- 봇: 알파-베타 + 기억표 + 되풀이는 비김. 쉬움 2수·흔들림 ±160·15% 엉뚱한 수, 보통 4수·±40, 어려움은 끝까지 깊어짐(40만 노드·0.6초, 방장 화면에서 바로 계산). 사자를 잡거나 안전하게 도착할 수 있으면 바로 둠. 어려움이 보통·쉬움을 거의 다 이김.

## 화면

- 3D: 공통 테이블 가운데 원목 판(3×4 칸, 양쪽 끝 줄 조금 어둡게) + 네모 타일 말(둥근 모서리, 먹선 껍질). 윗면 그림(`drawTile`, 2D 판과 같은 그림): 크림색 바탕, **주인 자리 색 테두리**(주사위 면 색 `SEAT_C`), 가운데 동물(캔버스로 직접 그림), 갈 수 있는 방향에 점. 그림 위쪽이 말의 앞이라 내 말은 화면 위, 상대 말은 아래를 봄.
- 병아리 타일 아랫면은 닭: 끝 줄에 닿으면 미끄러진 뒤 뒤집혀 닭(0.3초), 그다음 닭 타일로 바꿔 끼움.
- 포로 받침: 종류마다 칸 하나, 같은 종류 둘이면 겹쳐 놓음. 넓은 화면은 판 옆(내 것 오른쪽 아래부터 위로, 상대 것 왼쪽 위부터), 좁은 화면은 판 앞뒤 — 판이 더 크게 보이는 쪽(`d3Layout`). 잡힌 말은 내 받침으로 날아가며 돌아섬.
- 카메라: 바로 위(탑뷰, `tvBox`). 후를 잡으면 판을 돌려 내 말이 늘 아래.
- 표시: 마지막 수 노랑, 고른 말 초록(살짝 들림), 갈 칸 점, 잡을 칸 테두리, 미리 보기 반투명 타일, 못 움직이는 말을 누르면 빨강 + 금지 소리.
- 조작: 말·포로 누르기 → 칸 누르기(미리 보기) → [두기](두 번 눌러 놓기면 같은 칸 다시). 상대 차례에도 미리 고름. Esc는 내려놓기.
- 시작 연출: 로비 카메라 → 위, 판 내려앉음, 병아리 → 코끼리 → 기린 → 사자(쿵), 1.9초부터 주사위. 바로 시작은 말이 처음 자리로 미끄러지고(포로·닭도) 1초 뒤 알림.
- WebGL이 없으면 2D 판(SVG, 타일 그림은 같은 캔버스를 이미지로), 포로 줄은 판 위·아래.
- 홀로그램 말: 사자 타일 + 병아리 타일(`G.holoPiece`).
