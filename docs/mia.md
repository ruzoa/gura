# 미아 (`games/mia.js`)

사용자가 만든 오리지널 보드게임입니다. 내 말의 자리만 나에게 보이지 않고, 거리 변화로 위치를 추리해 깃발을 찾아갑니다. 화면 틀은 픽셀을 따릅니다. 이 기능을 바꾸면 이 문서를 고칩니다.

## 규칙 (2026-11-05 사용자와 확정)

- 판: 9×9, 위가 북. 칸 이름 A~I + 1~9(아래가 1). 기본 2명, 최대 4명.
- 시작 칸: 각자 다음 자리 사람의 말을 놓을 칸을 몰래 고름(제한 없음, 말끼리 같은 칸 가능). 시간이 지나면 무작위.
- 깃발: 각자 10면체 둘. 첫째 = 열, 둘째 = 행. 0은 다시 굴림(화면에는 최종 값만), 시작 칸과 같아도 다시 굴림. 가까워도 그대로 진행.
- 차례: 행동 두 번(2이동, 1벽 1이동, 2벽, 라운드 끝 판정은 그대로). 행동은 동서남북 한 칸 이동 또는 벽 하나. 두 번 모두 해야 차례가 끝남. 벽·판 끝으로 가면 알리지 않고 제자리, 차례는 씀.
- 벽: 칸과 칸 사이 한 칸 길이, 전체 40개를 똑같이 나눔(2명 20·3명 13·4명 10, `wallT` 8~80 설정), 남는 벽은 쓰지 않음. 어떤 칸도 끊어 놓을 수 없음(모든 칸이 이어져 있어야 함). 벽만 보고 판정하므로 설치 실패로 내 자리가 드러나지 않음. 가둠 승리 없음.
- 거리: 모두 한 번씩 하면 라운드 끝, 각자 자기 깃발까지 최단 거리를 자기만 받음. 처음에는 거리를 주지 않음(사용자 규칙 그대로).
- 승리: 라운드 끝에 자기 깃발에 있으면 승리. 여럿이면 함께 승리, 남은 사람 모두면 무승부.
- 제한 시간(기본 30초): 지나면 무작위 방향 이동. 항복·탈주하면 말·깃발이 사라지고 벽은 남음.
- 선: 첫 판은 공통 첫 차례 주사위(`pickfirst` 선택이면 방장이 고름), 바로 시작은 지난 판 선의 다음 사람(`H.miaLast`). 라운드마다 같은 순서.

## 엔진

- 칸 = `y*9+x`(y 0 = 북). 변 번호 = `칸*2`(동쪽 변) 또는 `칸*2+1`(남쪽 변), `w[변]` = 자리 + 1.
- `H.mia`: `cnt`, `A`, `ph`(place/roll/move/end), `rn`(끝난 라운드), `n`(행동 수), `pos`, `flag`, `roll`, `w`, `ws`, `left`, `done`, `hist`(자리별 `{a:방향 또는 4(벽),d:거리}`), `bel`(봇 후보 칸), `path`, `lm`, `res`.
- **비밀 지키기**: `snap`은 끝나기 전까지 받는 사람 자신의 `pos`를 -1로 보내고, 이동 결과·`path`도 보내지 않음. 시작 칸 단계는 자기가 고른 칸만. 진행 기록에도 부딪힘을 쓰지 않음. 효과음도 부딪혔을 때와 같음. 테스트가 이것을 확인함.
- 시작 칸 단계는 모두 동시: 안 고른 사람에게 `s.t=you`. 깃발 단계(`roll`)는 `rollMs(인원)` 동안 멈춤.
- 쉬움 봇: 자기 `pos`를 읽지 않음. 벽·깃발·받은 거리로 `bel`을 줄이고(`beliefMove`·`beliefFilter`), 20%는 무작위 벽(벽이 있을 때), 나머지는 평균 거리가 가장 줄어드는 방향(20% 무작위). 끊긴 사람을 대신할 때도 같은 후보를 씀. 처음은 쉬움만(`oneBotLv`).

## 화면

- 3D: 공통 테이블 가운데 원목 판, 안쪽 띠에 좌표, 바깥 띠에 동서남북. 모두 같은 방향에서 봄(바로 위, `tvBox`).
- 상대 말은 반투명, 내 말은 없음. 탈출구는 납작한 자리 색 코인(윗면에 열린 문과 화살표), 화면 이름은 탈출구(코드 이름은 `flag`). 같은 칸이면 작게 비켜 놓음. 벽은 각자 앞 보관대에 세워 두고(나는 아래, 나머지는 왼쪽·위·오른쪽) 세우면 보관대에서 날아감. 내 보관대를 눌러 벽 모드(내 차례면 끝 벽이 살짝 올라옴). 벽 버튼은 2D에만. 끝나면 내 말이 나타나고 지나온 길을 차례로 그림.
- 깃발 주사위: 사람마다 1.3초, 자리 색 진짜 10면체(오각 사다리꼴면체, 면마다 0~9) 둘이 구르고 나온 숫자 면이 위로 멈춘 뒤 깃발이 떨어짐. 0으로 다시 굴린 것은 보여 주지 않음.
- 조작: 내 차례에 남은 칸 수 둘레에 사다리꼴 방향 버튼이 생기고 누르면 바로 이동(확인 없음, 응답 전 두 번 눌림 막음). 벽 모드를 켜면 칸 안의 가까운 변이 골라지고 → [놓기](시작 칸·벽 모드일 때만 보임). 안 되는 벽은 빨간 벽 + 금지 소리. 벽 모드가 아닐 때 칸을 누르면 메모(✕ ↔ 지움). 메모는 `gura-mia-memo`에 그 판 동안 저장.
- 가운데 원이 남은 칸 수와 남은 행동 불 둘, 남은 칸 수(1라운드가 끝나기 전에는 `?`, 라운드가 끝날 때만 바뀌고 튐), 위쪽 왼쪽에 내 기록(방향·벽 + 거리). 키보드: 화살표(↑↓는 `bjUp`·`bjDown`, ←→는 `miaL`·`miaR`), 벽 X(`qmode`).
- 휴대폰 세로는 판 아래 `PAD_H`만큼 방향 단추 자리를 비움.
- WebGL이 없으면 2D 판(SVG), 주사위 없이 깃발이 차례로 나타남.
- 홀로그램 말: 깃발·벽·말(`G.holoPiece`).

## 균형

쉬움 봇끼리 평균 5~7라운드(2명 약 6.5, 3명 약 5.5, 4명 약 4.6, 각 30판). 사람 대국은 다를 수 있음.
