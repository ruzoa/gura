    플레이 방법

    1. 목표 : 손에 든 카드를 먼저 털어낸 사람이 승리합니다
    2. 시작 : 첫 번째 플레이어가 자음 하나를 정하고 1장 이상 뒷면으로 냅니다
    3. 진행 : 돌아가며 해당 자음 카드를 뒷면으로 내거나 패스합니다
    4. 구라! : 정해진 자음이 아닌 다른 카드를 낸 것 같다면 누구든 구라!를 외칠 수 있습니다
    5. 판정 : 거짓이면 카드를 낸 사람이, 진짜면 구라!를 외친 사람이 쌓인 카드를 전부 가져갑니다
    6. 패스 : 만약 모든 플레이어가 패스를 하면 쌓인 카드는 버려집니다.
    7. 별카드 : 모든 자음으로 인정됩니다
